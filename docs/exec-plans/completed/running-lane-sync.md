## 目标与范围

用户要求真正开始任务时同步到执行中列。本轮首次有效 running 回执将当前 Ready 原子移到 Doing，同时写入 started/moved；创建、绑定、blocked 及错误回执不移动。后续 running 不覆盖用户手动流转，其他业务列保持原样。
