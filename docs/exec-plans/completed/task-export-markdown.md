# 任务导出 Markdown 报告（时间区间）

- 状态：已完成（宿主内人工验收通过）
- 创建日期：2026-10-04
- 最后更新：2026-10-04
- 负责人：Codex
- 关联历史记录：[20261004-1925-task-export-markdown](../../histories/2026-10/20261004-1925-task-export-markdown.md)

## 目标

用户与 Agent 都能按时间区间导出当前看板任务为一份 Markdown 报告：默认区间为「今天往前推一个月」，
可显式指定开始/结束时间。报告写入磁盘（默认数据目录 `exports/`，可指定绝对路径），同时在工具结果中
返回完整 Markdown 供 Agent 读取；UI 生成后仅展示文件路径并提供「复制路径」。导出是只读业务：
不改任务、不改存储版本、不创建分支或执行请求。

## 范围

- 包含：
  - 新 MCP 工具 `task_export`（handlers + register + zod 契约），属业务工具组。
  - core 导出模块：区间解析与校验、区间命中筛选、Markdown 渲染、落盘路径解析与原子写入。
  - UI：设置菜单「导出报告」入口 + 导出对话框（开始/结束日期，默认今天与一个月前；范围选择与
    最近一个月/本月/上月快捷项；生成后展示文件路径与「复制路径」，剪贴板被拒时回退为选中文本），
    中英文案与样式。
  - 文档：README 工具契约表、AGENTS.md 工具列表、历史记录。
- 不包含：
  - CSV/JSON/PDF 导出、定时或增量导出、跨看板合并导出。
  - 自动提交、推送、分享或深链接打开导出文件（宿主能力未验证的入口一律不做）。
  - 执行链改动：导出不读写在途执行请求，不产生 `task_execution_*` 记录。

## 契约与口径

- 工具：`task_export`，参数 `boardId`（省略时仅单看板自动解析）、`start`、`end`、`scope`、`path`、`lang`。
- 区间解析：
  - `end` 缺省为今天（本地时区）当天结束 23:59:59.999；`start` 缺省为 `end` 所在日期往前一个月（同日 00:00，
    3 月 31 日回退到 2 月 28/29 日）；只给 `start` 且晚于今天时明确报 VALIDATION，不猜测区间。
  - `YYYY-MM-DD` 按本地自然日展开（start 取当日 00:00:00.000，end 取当日 23:59:59.999）；完整 ISO 时间按精确
    时刻；非法日期（如 2026-02-30）显式拒绝，不接受 JS 顺延；`start > end` 报 VALIDATION。
  - 报告头部标注时区偏移（如 `UTC+08:00`）并声明含边界，避免 UTC 与本地口径混淆。
- 命中口径：任务的 `createdAt` / `updatedAt` / `archivedAt` 任一落在区间内即导出，并在明细中写明命中字段。
  只按创建时间会漏掉区间内推进的老任务，只按更新时间会漏掉当月创建后未再变动的任务。
- 范围：`scope` 默认 `all`（含归档）——汇报应覆盖已经归档的完成项；`active` / `archived` 显式收窄。
- 落盘：默认 `<数据目录>/exports/<看板名>-<startDate>_<endDate>-<yyyyMMdd-HHmmss>.md`；显式 `path` 必须是绝对路径，
  指向已存在目录时补默认文件名，缺少 `.md` 后缀时补全；写入用同目录临时文件 + rename 原子替换。
  文件名携带生成时间戳（本地 yyyyMMdd-HHmmss），同区间的重复/并发导出各得一份文件不互相覆盖；
  同一秒内的极端冲突仍按覆盖处理（原子写入）。

## UI 入口与结果展示（2026-10-04 用户澄清）

- 入口：设置菜单（HeaderSettings）内的「导出报告」项，宽窄视图一致；不占头部独立图标位。
- 对话框只做区间/范围选择与提交；生成成功后**不展示报告内容、不触发浏览器下载**，
  仅展示落盘文件路径并提供「复制路径」按钮（剪贴板被宿主拒绝时回退为选中路径文本）。
  Agent 侧照常通过工具返回的 `markdown` 字段读取完整报告。

## 风险

- 时区与边界：默认区间按运行进程的本地时区计算，报告内显式标注偏移；测试断言使用本地时间构造，避免依赖 CI 时区。
- 覆盖与并发：UI 与 Agent 可能同时导出同一区间，原子写入保证不发生半截文件；覆盖不删除任务数据。
- 路径安全：仅接受绝对路径；默认写入数据目录 `exports/` 子目录，绝不写 `board.json`、不触碰任务与锁文件。
- 契约兼容：只新增只读工具与可选参数，存储保持 v4，不新增字段、不迁移数据；旧版本服务不认识 `task_export`
  但不影响既有数据；回滚方式为移除工具注册与 UI 入口，已导出的文件保留（用户可自行删除）。
- 返回体体积：区间过大或任务很多时 Markdown 较长。本轮直接返回全文（UI 预览与复制需要），
  描述字段截断上限 1200 字符；若后续出现明显性能问题再评估精简参数，记入技术债。
- 宿主能力：复制到剪贴板失败不视为导出失败（文件已落盘），回退为可选中文本；不新增未验证的宿主调用。

## 里程碑与并行边界

1. 固定契约与口径（工具名、参数、默认区间、落盘位置、报告结构、语言开关）。
2. core：`packages/core/src/export.ts`（区间/筛选/渲染/路径/写入）+ `BoardEngine.exportTasks` + 单测。
3. MCP：`handlers.taskExport` + `register` 工具 schema + 契约测试 + `scripts/smoke.mjs` 计数与落盘检查。
4. UI：`ExportDialog` 组件、`AppHeader` 入口、`BoardContext` 调用、i18n 中英词条、样式。
5. 整合验证、文档更新、历史记录、归档计划。

- 可并行任务、负责人及文件范围：单人在一个工作区内串行推进；若要并行，core 与 UI 可分属不同负责人，
  但 UI 必须等 `task_export` 契约（参数名与返回字段）冻结后再实现，MCP 注册不得与 core 同时改 `engine.ts`。
- 必须串行的依赖：契约 → core → MCP 注册 → UI → 冒烟与浏览器验证。

## 决策记录

- 2026-10-04：导出为**只读新增工具** `task_export`，不走「写任务字段」方案——报告是一次性产物，
  不进入任务生命周期。
- 2026-10-04：默认区间为「今天往前一个月」（不是自然月），与用户表述一致；按本地时区展开自然日。
- 2026-10-04：命中口径取创建/更新/归档任一命中，避免漏掉区间内被推进的老任务。
- 2026-10-04：`scope` 默认 `all`（含归档），因为月报需要覆盖已归档的完成项。
- 2026-10-04：落盘默认进入数据目录 `exports/`，避免默认污染用户仓库；Agent 需要仓库内文件时显式传 `path`。
- 2026-10-04：报告语言由 `lang` 参数决定（默认 `zh`，UI 传当前界面语言），不在服务端读界面状态。
- 2026-10-04（用户澄清）：导出入口放在设置菜单下，宽窄视图一致。
- 2026-10-04（用户澄清）：生成后不展示报告内容、不触发下载，只显示文件路径 + 「复制路径」按钮。
- 2026-10-04（用户澄清）：文件名加生成时间戳（yyyyMMdd-HHmmss），避免同区间重复/并发导出冲突。
